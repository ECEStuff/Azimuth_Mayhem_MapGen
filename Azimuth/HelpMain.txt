Azimuth User Guide

Getting started
Choose your Mayhem 3 root folder and X3 save folder on the left. Click either path to change it. Back up existing saves before switching galaxies for the first time.

Generate a galaxy
Choose a galaxy size, shape and expansion stage. Void sets the target percentage of empty cells within the selected size limits. Xenon sets the percentage of actual sectors (excluding voids) for a Standard start, rounded up. Peaceful Start places one Xenon sector and Chaotic Start targets 50%. Click Generate Sectors to build the map.

Expansion allocates unknown space from the sectors remaining after Xenon: Early 60%, Average 40%, Advanced 20%, rounded up. Races receive the remainder. Origin gives one sector per race. Sector Spread adjusts the relative race quotas; equal values cancel out.

Gates are finalized before ownership is assigned. Race territories grow through gates from separated seeds and do not directly border other non-Xenon races. Unknown or Xenon space forms the separator. Starts are at least four gate jumps apart; generation seeks greater, balanced separation. Exact equal distances are not guaranteed.

Every new map has at least four unknown one-gate enclaves and a Xenon portal enclave. Xenon prefer other enclaves. Clustered Xenons allows multiple BFS clusters in Standard; Chaotic forces one connected Xenon territory. Limited Enclaves reduces optional dead ends but retains required enclaves. Gate Density controls the complete network, not only borders.

The generated race seeds are guaranteed de jure for their owners, including after stat rerolls. They are separate from the player start overrides. Generation retries difficult layouts without relaxing constraints. If no plan is found, the previous map is retained.

Edit the map
Double-click an occupied sector to edit its stats or gates. Double-click a void to add a sector. Right-click a tile to add or remove a sector within the size limits. New sectors start without gates. Check the network warnings after editing. Regenerate Gates must preserve the new-map territory rules or it restores the previous gates. Arbitrary manual ownership or gate edits can invalidate generation guarantees. Legacy maps retain their old minimum of one unknown enclave.
Reroll Sector Stats rerolls sector attributes across the galaxy. Choose None, Extra Sector Stats or Saboteur Mode before generating a galaxy. Extra Sector Stats increases population, research and station support by 20%. In Expanded, total supply is reduced by 20% and maximum specialization falls from 20% to 15%. Saboteur Mode reduces population, research and station support by 20%. In Expanded, maximum specialization rises from 20% to 30%, and you gain one additional perk slot. Rerolling stats and editing a sector use the stored modifier. Use Find to locate a sector and Export PNG to save an image of the current map.

Save and play
Open Save/Load Galaxy, enter a name and click Save. Load reopens a saved galaxy in the editor. Set Active installs the selected galaxy for X3. If Azimuth cannot identify your existing save slots, select the galaxy those saves belong to and click Identify Current Saves before switching.

Edit game settings
Open Config and choose page 9972 or 9973. Select a section or filter by text, then edit the Current value. Restore Selected uses the reference default for one setting. Save and Close writes the installed configuration file. Save Preset writes a separate JSON file.

Ships and Weapons Editor
-------------------------
Located in the toolbar, there is a launch icon for the Ships and Weapons Editor.
The purpose of this editor is NOT to allow editing of individual ships or weapons, as you can already do that through the use
of the "X3 Editor 2".


1. This editor will allow you to globally randomize Weapons stats, providing some unique variation for each game you play.
	Key weapon stats are adjusted by +/- 20% and uniquely computed for EACH weapon.  Some may go up and others down.
2. The editor will also allow you to randomize or adjust up/down key ship statistics based on a Race.  
	This will allow you to pick any given race and apply either a random adjustment to all their ships, or you can
	lower or raise their ship capabilities.  If you feel the Paranid are too strong, simply select their race
	from the drop-down and select "lower all ship status for Race" and click "Execute" !
3. The Editor also allows you to restore the game defaults.

Note:  If something doesn't appear to be working, check your /addon/types/ folder and ensure there are no TShips.pck or TBullets.pck files there. 
	If you find any, either delete or rename them to .temp or something else.

This editor works by allowing you to graphically edit the Default TShips.txt and TBullets.txt files. (These were extracted from Mayhem 3's 10.cat file.)
Once these files are adjusted by this editor, it writes them out to the /addon/types/ folder in your Mayhem 3 install folder, where
these settings will automatically Override the default values found in the 10.cat file in the game.  You can certainly modify these values
by hand, but they are a bit hard to parse and read.  The editor does this for you, and also allows the important values to be randomized globally
or by Race.

	Stats Modified
	---------------
	All stats listed here are modified by a random value between -20% and +20% computed uniquely for EACH Weapon or Ship.
	If you choose to "Raise" ship stats for a race, each ship in that race will receive a change of +10% to +20% computed randomly for EACH ship in that race.  
	If you choose to "Lower" ship stats for a race, each ship in that race will receive a change of -10% to -20% computed randomly for EACH ship in that race. 

	1. Weapons Stats:	
		. Hull Damage (both in/out of system)
		. Shield Damage (both in/out of system)
		. Lifetime (laser range)
	2. Ship Stats:
		. Cargo min, Cargo max
		. Production rel. value (NPC), Production rel. val (player)
		. Yaw, Pitch, Roll
		. Speed (base)
		. Hull strength
		. Power (shield recharge)
		. Weapons Energy
