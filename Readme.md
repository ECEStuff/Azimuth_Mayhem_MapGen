# Azimuth

**Galaxy Generator and Editor for X3: Albion Prelude — Mayhem**

Azimuth (formerly ZMap Expanded) is an independently maintained galaxy generator and editor based on the original ZMap by Mordan (Hairless-Ape).

Originally developed to support [Mayhem Expanded](https://github.com/ECEStuff/Mayhem-Expanded), Azimuth builds upon ZMap's foundations with expanded functionality, improved editing tools, and compatibility enhancements for multiple Mayhem editions.

## Background

The original Mayhem 3 galaxy generator was developed by Joubarbe and released with Mayhem 3 in 2020. Its source code was lost and was therefore unavailable for subsequent ZMap development.

In 2022, Mordan (Hairless-Ape) developed [ZMap](https://forum.egosoft.com/viewtopic.php?t=449012) by reverse-engineering the original generator's output, creating a new galaxy generator and editor. ZMap's source code was subsequently made publicly available on GitHub through version 1.8.2.

Later ZMap development shifted toward exclusive support for Mayhem: Friend or Foe (FoF). Azimuth is derived from the publicly released [ZMap v1.8.2 source code](https://github.com/Hairless-Ape/ZMap/releases/tag/V1.8.2). It retains much of ZMap's original architecture and interface while introducing new functionality and independently maintained improvements.

## Why Azimuth?

Azimuth originated as ZMap Add-Ons, briefly renamed ZMap Expanded, to support the Xenon game start and additional galaxy generation requirements introduced by the project now known as Mayhem Expanded.

As the projects evolved separately, differences in compatibility requirements, implementation approaches, and development priorities reinforced the need for an independent project identity.

The Azimuth name reflects this separation. As development progressed, overlapping functionality, including the configuration editor and sector editing tools, evolved through different implementations. Retaining the ZMap name or adopting a shared versioning scheme could incorrectly imply that one application supersedes the other. A distinct identity avoids confusion over compatibility, development history, and maintenance responsibility while preserving attribution to ZMap's original creator, Mordan.

As later FoF-specific ZMap development continued without publicly released source code, Azimuth also serves to preserve a source-available development path based on ZMap v1.8.2. This allows its implementation to be examined, maintained, and improved independently, subject to applicable licensing and attribution requirements.

Azimuth is designed to provide consistent galaxy generation and editing functionality across all supported Mayhem editions, from Zero Hour onward, including Expanded. Genuine technical limitations and compatibility requirements remain respected.

Independent development allows Azimuth to maintain its own roadmap, compatibility policies, and release schedule while providing consistent galaxy generation, editing, and configuration functionality across supported Mayhem editions, from Zero Hour onward, including Expanded.

## Development

Azimuth is maintained by herobetty.

Development focuses on:

- Expanding galaxy generation and editing capabilities.
- Maintaining compatibility with supported Mayhem editions from Zero Hour onward, including Expanded.
- Fixing bugs and improving reliability.
- Providing additional customization options and quality-of-life improvements.
- Maintaining source availability, development transparency, and support for community contributions.

Base Mayhem 3 is outside the supported compatibility scope because it lacks Terran support.
