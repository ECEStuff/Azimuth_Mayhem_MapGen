# Azimuth

**Galaxy Generator and Editor for X3: Albion Prelude — Mayhem 3**

Azimuth (formerly ZMap Expanded) is an independently maintained galaxy generator and editor based on the original ZMap by Mordan (Hairless-Ape).

Originally developed to support [Mayhem Expanded](https://github.com/ECEStuff/Mayhem-Expanded), Azimuth builds upon ZMap's existing functionality with additional features, improvements, and compatibility enhancements.

## Background

ZMap was originally developed by Mordan, who publicly released its source code on GitHub as version 1.8.2.

Azimuth is derived from that publicly released version and retains much of ZMap's original architecture and interface while introducing new functionality and independently maintained improvements.

ZMap for Mayhem: Friend or Foe (FoF) is a separate, proprietary development and is not part of this repository.

## Development

Azimuth is maintained by herobetty.

Development focuses on:

- Expanding galaxy generation and editing capabilities.
- Improving compatibility with Mayhem 3 and its derivatives.
- Fixing bugs and improving existing functionality.
- Providing additional customization options and quality-of-life improvements.
- Maintaining transparency and supporting community contributions.
